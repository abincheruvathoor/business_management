# RetailBot Frontend Prototype

This is a frontend-only React/Vite prototype for the MCA mini project:
**Business Management Using Chatbot**

## Run
1. Install Node.js.
2. Open this folder in VS Code.
3. Run:
   npm install
   npm run dev
4. Open the local URL shown by Vite.

## Prototype
- Dashboard
- Products
- Inventory
- Sales
- Purchase Orders
- Reports
- Guided Chatbot
- Inventory mnemonic concept

The current data is mock data. The next phase is to connect React to a Node/Express + MongoDB backend and then connect the same chatbot workflow to Telegram/WhatsApp.
